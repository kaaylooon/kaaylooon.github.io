O Katálogo é uma aplicação web completa construída com Flask (Python). Ela funciona como um catálogo online para negócios locais, onde usuários podem:

- Cadastrar novos estabelecimentos
- Avaliar e comentar serviços
- Visualizar informações como endereço, horário e contato

É um projeto que coloca em prática conceitos de CRUD, autenticação, banco de dados (SQLite/PostgreSQL) e design responsivo.
